## Note on committing these PDFs

The audit kit (`AUDIT_RULES.md`) recommends keeping source PDFs local-only and not committing them to a public repo. This repo's existing `audit-sources/Science/Form-2/` precedent commits its PDFs instead. Decide which convention to follow for Geography before running `git add` on the PDFs placed here.
