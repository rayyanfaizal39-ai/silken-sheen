# Original Nova Studio media

The files in `audio/` and `creatures/` were authored specifically for this project:

- `starlit-sanctuary.mp3`: original 56 BPM piano, softly bowed harmonic strings and celestial bell arrangement, 34.286 seconds, cyclic reverb and seamless decoded loop.
- `nova-magic.mp3`: fourteen original synthesized chime, flame, water, sparkle, whoosh and orchestral flourish cues; cue offsets are in `src/features/nova-cards/sanctuary/audio-cues.ts`.
- `phoenix.svg`, `fox.svg`: original lightweight vector creature portraits.
- `islands.svg`, `lagoon.svg`, `forest.svg`: original vector environment thumbnails.

No third-party samples, commercial recordings, paid generation APIs or downloaded stock assets were used in these files. Reproducible authoring sources are `scripts/generate-nova-audio.py` and `scripts/generate-nova-illustrations.mjs`. Python/numpy and ffmpeg are authoring tools only; the application has no new runtime dependency.
