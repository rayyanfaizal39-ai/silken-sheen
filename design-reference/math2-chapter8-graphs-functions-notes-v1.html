8.1

FunctionsFungsi

📖 The IdeaIdea Utama

A function is a rule where every input has EXACTLY ONE output — never two. Feed in a number, the rule does its thing, one answer comes out. Fungsi ialah peraturan di mana setiap input mempunyai TEPAT SATU output — tidak pernah dua. Masukkan nombor, peraturan buat kerjanya, satu jawapan keluar.

Function NotationTatatanda Fungsi
f(x) = x + 3
Read "f of x" — the function f applied to input xBaca "f bagi x" — fungsi f dikenakan pada input x
Worked ExampleContoh Berpandu
Set P = {1,2,3} maps to Set Q = {4,5,6} by "adding 3". Write this as (a) ordered pairs (b) an equation.Set P = {1,2,3} memetakan Set Q = {4,5,6} dengan "tambah 3". Tulis sebagai (a) pasangan tertib (b) persamaan.
🤝 Try It YourselfCuba Sendiri

Is {(1,2),(2,3),(1,4),(3,5)} a function? Explain.Adakah {(1,2),(2,3),(1,4),(3,5)} fungsi? Jelaskan.

👁️ Show AnswerTunjuk Jawapan
No — the input 1 appears twice with two different outputs (2 and 4). One input must give only one output. Tidak — input 1 muncul dua kali dengan dua output berbeza (2 dan 4). Satu input mesti beri satu output sahaja.
⚠️ Watch OutBerhati-hati
❌Assuming many-to-one relations (several inputs sharing one output) aren't functions.Menganggap perhubungan banyak-ke-satu (beberapa input kongsi satu output) bukan fungsi.
✅Many-to-one IS still a function — the rule only breaks when ONE input gives MULTIPLE outputs.Banyak-ke-satu MASIH fungsi — peraturan hanya pecah bila SATU input beri BANYAK output.

8.2

Graphs of FunctionsGraf Fungsi

📖 The IdeaIdea Utama

Plug in several x-values, get their y-values, plot the (x,y) points, then join them. A straight-line rule (like y=2x+4) draws a LINE. A squared rule (like y=x²−2x−3) draws a curved PARABOLA. Masukkan beberapa nilai-x, dapatkan nilai-y, plot titik (x,y), kemudian sambungkan. Peraturan garis lurus (seperti y=2x+4) melukis GARIS. Peraturan kuasa dua (seperti y=x²−2x−3) melukis PARABOLA melengkung.

Worked Example — LinearContoh Berpandu — Linear
Complete the table for y = 2x + 4, then plot the graph, for x from −2 to 3.Lengkapkan jadual bagi y = 2x + 4, kemudian plot graf, untuk x dari −2 hingga 3.
Worked Example — QuadraticContoh Berpandu — Kuasa Dua
Complete the table for y = x² − 2x − 3, then plot the graph, for x from −2 to 4.Lengkapkan jadual bagi y = x² − 2x − 3, kemudian plot graf, untuk x dari −2 hingga 4.
🤝 Try It YourselfCuba Sendiri

For y = 5 − x, find y when x = −2, −1, 0, 1.Bagi y = 5 − x, cari y apabila x = −2, −1, 0, 1.

👁️ Show AnswerTunjuk Jawapan
x=−2: y=7. x=−1: y=6. x=0: y=5. x=1: y=4.
⚠️ Watch OutBerhati-hati
❌Joining plotted points with straight segments for a QUADRATIC function.Menyambung titik diplot dengan segmen lurus untuk fungsi KUASA DUA.
✅Quadratic functions always form a SMOOTH curve (parabola) — never straight lines between points.Fungsi kuasa dua sentiasa bentuk lengkung LICIN (parabola) — tidak pernah garis lurus antara titik.
