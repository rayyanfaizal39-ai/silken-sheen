11.1

SetSet

📖 The IdeaIdea Utama

Objects with a common characteristic can be grouped into a set. Each object inside is an element. A set can be written three ways: by description (a sentence), by listing ({red, white, blue, yellow}), or by set builder notation ({x : x is a colour of Jalur Gemilang}). Objek dengan ciri sepunya boleh dikumpulkan kepada set. Setiap objek di dalamnya ialah unsur. Set boleh ditulis tiga cara: melalui perihalan (ayat), melalui penyenaraian ({merah, putih, biru, kuning}), atau melalui tatatanda pembina set ({x : x ialah warna Jalur Gemilang}).

Symbol ∈ means "is an element of"; ∉ means "is not an element of". n(A) counts the number of elements in set A. Sets with EXACTLY the same elements are equal sets. Simbol ∈ bermaksud "ialah unsur bagi"; ∉ bermaksud "bukan unsur bagi". n(A) mengira bilangan unsur dalam set A. Set dengan unsur yang SAMA TEPAT ialah set sama.

A = {red, white, blue, yellow}

🤝 Try It YourselfCuba Sendiri

Given P = {x : x is a prime number and 0 < x < 20}, list P. Is 8 an element of P?Diberi P = {x : x nombor perdana dan 0 < x < 20}, senaraikan P. Adakah 8 unsur bagi P?

👁️ Show AnswerTunjuk Jawapan
P = {2, 3, 5, 7, 11, 13, 17, 19}. 8 is not prime, so 8 ∉ P. P = {2, 3, 5, 7, 11, 13, 17, 19}. 8 bukan perdana, jadi 8 ∉ P.
⚠️ Watch OutBerhati-hati
❌Repeating a letter that appears twice in a word, e.g. writing {M,A,L,A,Y,S,I,A} for "MALAYSIA".Mengulang huruf yang muncul dua kali dalam perkataan, cth. tulis {M,A,L,A,Y,S,I,A} bagi "MALAYSIA".
✅Each element is listed ONCE only, even if it repeats in the original word: {M,A,L,Y,S,I}.Setiap unsur disenaraikan SEKALI sahaja, walaupun ia berulang dalam perkataan asal: {M,A,L,Y,S,I}.

11.2

Venn Diagrams, Universal Sets, Complement of a Set and SubsetsGambar Rajah Venn, Set Semesta, Pelengkap Set dan Subset

📖 The IdeaIdea Utama

The universal set (ξ) contains everything under discussion — drawn as a rectangle. A set inside it is a circle. Everything in ξ but NOT in that circle is the set's complement (A′). If EVERY element of set B is also in set A, then B is a subset of A, written B ⊂ A — drawn as a smaller circle inside the bigger one. Set semesta (ξ) mengandungi segala yang dibincangkan — dilukis sebagai segi empat tepat. Set di dalamnya ialah bulatan. Segala dalam ξ tetapi BUKAN dalam bulatan itu ialah pelengkap set itu (A′). Jika SETIAP unsur set B juga dalam set A, maka B ialah subset bagi A, ditulis B ⊂ A — dilukis sebagai bulatan lebih kecil dalam bulatan lebih besar.

Number of SubsetsBilangan Subset
Subsets of a set with n elements = 2ⁿ
The empty set ∅ and the set itself are ALWAYS subsets of any set.Set kosong ∅ dan set itu sendiri SENTIASA subset bagi sebarang set.
Worked ExampleContoh Berpandu
List all possible subsets of {a, b, c}.Senaraikan semua subset mungkin bagi {a, b, c}.
🤝 Try It YourselfCuba Sendiri

ξ = {x : 1 ≤ x ≤ 10, x is an integer}, P = {perfect squares less than 10}. Find P′.ξ = {x : 1 ≤ x ≤ 10, x integer}, P = {kuasa dua sempurna kurang daripada 10}. Cari P′.

👁️ Show AnswerTunjuk Jawapan
ξ={1..10}. P={1,4,9}. Everything in ξ NOT in P: P′={2,3,5,6,7,8,10}. ξ={1..10}. P={1,4,9}. Segala dalam ξ BUKAN dalam P: P′={2,3,5,6,7,8,10}.
⚠️ Watch OutBerhati-hati
❌Forgetting the empty set ∅ when listing all subsets of a set.Terlupa set kosong ∅ apabila menyenaraikan semua subset sesuatu set.
✅∅ is ALWAYS a subset of every set — a set with n elements has exactly 2ⁿ subsets, including ∅ and the full set.∅ SENTIASA subset bagi setiap set — set dengan n unsur mempunyai tepat 2ⁿ subset, termasuk ∅ dan set penuh.
