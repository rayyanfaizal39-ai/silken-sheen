Patterns and SequencesPola dan Jujukan

A sunflower's seeds spiral in a pattern nature repeats everywhere. This chapter is about spotting that ONE repeating rule, so you can predict what comes next without counting all the way there. Biji bunga matahari melingkar dalam pola alam ulangi di mana-mana. Bab ini tentang mengesan SATU peraturan berulang itu, supaya anda boleh ramal apa seterusnya tanpa mengira sepanjang jalan.

1.1

PatternsPola

📖 The IdeaIdea Utama

A pattern is a list that follows ONE repeated rule — always add the same amount, or always multiply by the same amount. Watch the dots below grow: every new step adds exactly 3 more. Pola ialah senarai mengikut SATU peraturan berulang — sentiasa tambah jumlah sama, atau sentiasa darab dengan jumlah sama. Lihat titik di bawah berkembang: setiap langkah baharu tambah tepat 3 lagi.

Two Ways a Pattern Can RepeatDua Cara Pola Boleh Berulang
+d / −d   or   ×r / ÷r
If gaps aren't constant, try RATIOS instead (divide each term by the last)Jika jurang tidak tetap, cuba NISBAH pula (bahagi setiap sebutan dengan yang lepas)
Worked ExampleContoh Berpandu
Find the pattern: (a) −10, −4, 2, 8, ... (b) 2, 6, 18, 54, ...Cari pola: (a) −10, −4, 2, 8, ... (b) 2, 6, 18, 54, ...
🤝 Try It YourselfCuba Sendiri

Complete the Fibonacci sequence: 0, 1, 1, __, __, __, 8, 13, __, ...Lengkapkan jujukan Fibonacci: 0, 1, 1, __, __, __, 8, 13, __, ...

👁️ Show AnswerTunjuk Jawapan
Each term is the sum of the two before it: 0,1,1,2,3,5,8,13,21. Setiap sebutan ialah jumlah dua sebutan sebelumnya: 0,1,1,2,3,5,8,13,21.
⚠️ Watch OutBerhati-hati
❌Only checking ADDITION and giving up if the gaps aren't equal.Hanya semak TAMBAH dan berhenti jika jurang tidak sama.
✅If gaps change but keep growing, try dividing consecutive terms — the pattern might be multiplication.Jika jurang berubah tetapi terus membesar, cuba bahagi sebutan berturutan — pola mungkin pendaraban.

SequencesJujukan

📖 The IdeaIdea Utama

A sequence is a pattern where the SAME rule works for every single gap, all the way through — not just the first one or two. Jujukan ialah pola di mana peraturan SAMA berfungsi untuk setiap jurang, sepanjangnya — bukan hanya satu atau dua yang pertama.

Worked ExampleContoh Berpandu
Is this a sequence? (a) −10, −6, −2, 2, 6, ... (b) 4, 5, −7, 10, −14, ...Adakah ini jujukan? (a) −10, −6, −2, 2, 6, ... (b) 4, 5, −7, 10, −14, ...
🤝 Try It YourselfCuba Sendiri

Complete: 7, 13, __, 25, __, __, ...Lengkapkan: 7, 13, __, 25, __, __, ...

👁️ Show AnswerTunjuk Jawapan
13−7=6, so the rule is +6: 7,13,19,25,31,37. 13−7=6, jadi peraturan +6: 7,13,19,25,31,37.
⚠️ Watch OutBerhati-hati
❌Checking only the FIRST gap and assuming the rest matches.Semak hanya jurang PERTAMA dan anggap selebihnya sepadan.
✅One broken gap disqualifies the whole list — always check EVERY gap.Satu jurang pecah membatalkan keseluruhan senarai — sentiasa semak SETIAP jurang.

1.3

Patterns and SequencesPola dan Jujukan

📖 The IdeaIdea Utama

To find the 50th seat number without counting all the way there, you need a shortcut formula — the nth term, written Tₙ. Feed in a position, get back the value at that position. Untuk cari nombor kerusi ke-50 tanpa mengira sepanjang jalan, anda perlukan formula jalan pintas — sebutan ke-n, ditulis Tₙ. Masukkan kedudukan, dapat semula nilai pada kedudukan itu.

Three Ways to Describe One PatternTiga Cara Terangkan Satu Pola
Numbers → Words → AlgebraNombor → Perkataan → Algebra
1+8(0), 1+8(1)... → "add 8 to the previous" → 1+8n
Worked ExampleContoh Berpandu
State the 5th term for the sequence 2, 10, 18, ...Nyatakan sebutan ke-5 bagi jujukan 2, 10, 18, ...
🤝 Try It YourselfCuba Sendiri

Given 65, 60, 55, 50, ..., which term equals 40?Diberi 65, 60, 55, 50, ..., sebutan yang manakah bersamaan 40?

👁️ Show AnswerTunjuk Jawapan
Subtract 5 each time: 65,60,55,50,45,40 — that's the 6th term. Tolak 5 setiap kali: 65,60,55,50,45,40 — itu sebutan ke-6.
⚠️ Watch OutBerhati-hati
❌Confusing the VALUE of a term with its POSITION.Mengelirukan NILAI sebutan dengan KEDUDUKANnya.
✅"Find the 5th term" wants the VALUE there. "Which term equals 40" wants the POSITION."Cari sebutan ke-5" mahu NILAI di situ. "Sebutan mana bersamaan 40" mahu KEDUDUKAN.
✏️ Uji DiriUji Diri
EasyMudah
MediumSederhana
HardSukar
