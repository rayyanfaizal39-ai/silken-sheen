## 7. FINDINGS

### CRITICAL

**C-01 · Stellar life cycle is collapsed into a single linear chain; the supergiant stage is missing**

- **Location:** `interactive-bm.ts:76-87`, `interactive-dlp.ts` (same block) — the `sequence` block
- **Renders as:** a strictly linear stepper (numbered buttons 1–5, "Mula" disabled at step 1). Steps
  observed live: **Nebula → Protobintang → Bintang jujukan utama → Gergasi merah → Peringkat akhir**
- **Source (Rajah 11.1, p.242 + prose p.243) has three branches:**

| Branch | Source pathway |
|---|---|
| Medium | Nebula → **bintang bersaiz sederhana** → raksasa merah → **kerdil putih** |
| Large | Nebula → **bintang besar** → raksasa merah → **super raksasa** → supernova → **bintang neutron** |
| Super-large | Nebula → **bintang super besar** → raksasa merah → **super raksasa** → supernova → **lohong hitam** |

- **What the learner gets instead:** one path, with all three endpoints compressed into step 5's
  prose — *"Bintang kecil/sederhana menjadi kerdil putih secara senyap. Bintang besar meletup sebagai
  supernova — meninggalkan bintang neutron, atau bagi bintang yang sangat besar, sebuah lohong hitam"*.
  Verified live: `allThreeEndpointsInOneStep: true`.
- **The `super raksasa` / supergiant stage is entirely absent from the life cycle.** Measured across
  the rendered chapter: `super raksasa` = 0 and `supergergasi` = 0 within the sequence; *supergergasi*
  appears only in the unrelated **size** flip-cards. Both large-star branches therefore skip a stage
  the source draws.
- **Impact:** a learner stepping through the interactive sees every star following one route. The
  brief is explicit — *"Do NOT allow a single linear chain for all stars"* and *"A wrong branch
  endpoint is a blocking HIGH/CRITICAL defect."*
- **Targeted fix:** replace the linear `sequence` with a branching diagram (a new deterministic SVG,
  in the manner of the Chapter 10 figures) that renders three visually divergent paths with correct
  arrow directions, using only source terms and including the *super raksasa* stage.
